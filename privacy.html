Privacy policy

Riven Maker Backups is a private backup and recovery application operated by Baback Rashtizadeh. Updated 25 October 2026.

Google account access

Only the Google Drive drive.file permission is requested. It is used to create a dedicated backup folder, upload encrypted recovery archives, verify and download those archives, and permanently delete older archives created by this application after a successful replacement. The application does not request access to unrelated Drive files.

Data and encryption

Archives may contain Riven Maker databases, application files, configuration and recovery credentials. Contents and filenames are encrypted with rclone crypt before upload. Authorization tokens and encryption configuration are kept in private access-restricted files. A separate private recovery copy is held by the owner.

Use and retention

Google user data is used only to provide backup and recovery. It is not sold, used for advertising, shared with unrelated applications, or used to train AI models. The dedicated folder remains Restricted. Only the newest verified successful archive is retained; a failed replacement does not intentionally remove the previous successful archive.

Control and contact

The owner can revoke authorization in their Google account's connected-app settings and delete the backup folder. Deleting archives or losing the independent encryption configuration may make recovery impossible. Contact the operator via the operator's GitHub profile.
