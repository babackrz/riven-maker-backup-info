Riven Maker Backups

A private recovery tool for the Riven Maker application, operated by Baback Rashtizadeh.

The tool creates encrypted recovery archives and stores them in a dedicated, restricted folder in the owner's Google Drive. It requests only permission to create and manage files it creates (drive.file), not general access to the owner's Drive.

Encryption occurs before upload. Only the newest verified recovery archive is retained. This application does not execute financial transactions through Google Drive.
